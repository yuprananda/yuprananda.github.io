# Public website images

These assets are intentionally committed: GitHub Pages needs them to display the site.

- `portrait-color.webp`: optimized transparent color cutout; CSS displays grayscale until hover. Replace with your own portrait when forking. The PNG source remains only in the ignored local archive.
- `logo_MBB.png`: owner-supplied PT MBB logo. Its generous source whitespace is cropped only by CSS. Preserve logo proportions if replacing it.
- `bicless-*-real.webp`: screenshots captured from the running application at 1600 × 1000. Visible employee names and identity numbers were anonymized before capture; employee list dates were replaced too. The database was not changed. Recheck screenshots before publishing.
- `favicon.svg`: initial mark; replace when changing the site's identity.

Use paths such as `assets/images/my-project.webp` in content.js/app.js. Keep width/height attributes consistent with the source aspect ratio. Do not publish confidential information or credentials. Reuse permissions are described in ../../ASSETS.md.
