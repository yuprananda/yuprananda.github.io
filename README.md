# Yu Prananda — Portfolio

A bilingual (English / Indonesian) portfolio site for Yu Prananda, built with Astro and deployed to GitHub Pages.

## Local development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

Pushing to `main` builds and deploys the site through GitHub Actions. The published site is available at <https://yuprananda.github.io>.
